# Security policy

Please **do not** open a public issue for security problems.

Report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this repository (private vulnerability reporting). Include steps to reproduce and the impact you expect. You'll get a reply within a few days.

In scope: auth bypass, reading or changing another user's data, injection, secrets exposure.
Out of scope: issues that need a compromised device, brute-force rate limits (handled by Supabase Auth), and self-hosted deployments that skip the setup steps in the README.
